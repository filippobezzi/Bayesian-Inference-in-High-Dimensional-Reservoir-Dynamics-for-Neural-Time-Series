# Bayesian-Inference-in-High-Dimensional-Reservoir-Dynamics-for-Neural-Time-Series
Bayesian Inference in High-Dimensional Reservoir Dynamics for Neural Time Series

This project will adapt the framework presented in the paper "Probabilistic Load Forecasting With Reservoir Computing" [https://github.com/eloMG/Probabilistic-load-forecasting-with-Reservoir-Computing] specifically the comparison of Bayesian methods to neural signals as the time series generated by a complex dynamical system.
